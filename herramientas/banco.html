L'app à montrer
Ajouter ou modifier un terminal
La liste vit dans terminaux.js, à côté de ce fichier. Une ligne par appareil :
["Nom", largeur, hauteur]

Ce sont des pixels CSS, pas la résolution du fabricant : divisez la résolution par la densité de l'écran. Le Redmi 14C affiche 720 px de large pour une densité de 2 — il vaut donc 360.

"defaut" doit reprendre exactement un nom de la liste. Guillemets doubles partout, et pas de virgule après le dernier élément d'une liste — le contenu est du JSON, il se vérifie.

Les commentaires /* … */ sont permis, y compris entre les accolades : le vérificateur les enlève avant de lire.

Pour contrôler le fichier :
python3 -c "import re,json;s=re.sub(r'/\*.*?\*/','',open('terminaux.js').read(),flags=re.S);json.loads(s[s.index('{'):s.rindex('}')+1]);print('OK')"
